📥 How to Save Any Document as PDF for Google Drive


Method A: Browser PDF Export (1-Click)

1. Click any of the **Printable A4 / PDF Export Links** in the table above.

2. Click the **`🖨️ Save as A4 PDF`** button at the top of the page (or press `Ctrl + P` / `Cmd + P`).

3. Set Destination to **Save as PDF** and click **Save**.

4. Upload the generated PDF file directly to your Google Drive.

Run the built-in offline converter script in your project root:
