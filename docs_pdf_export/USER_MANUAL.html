    3. Link Analysis Graph Masterclass


    Canvas Interactivity & Controls:

  • **Pan Canvas**: Click and drag any empty area of the graph canvas to move 360°.
  • **Zoom**: Scroll mouse wheel or use floating toolbar buttons `[ + ]` and `[ − ]`.
  • **Drag Nodes**: Click and drag any entity node to reposition branches or clear visual overlaps.
  • **Re-Center Root**: Click `[ 🎯 ]` on the floating toolbar to instantly center and zoom into the root target node.
  • **Layout Engines**: Use top buttons to toggle between `Tree (Root Top)`, `Radial`, `Hierarchy`, and `Compact`.


    • 4. CCTV & DVR Surveillance Forensics Operations


    1. Navigate to **📹 CCTV / DVR Forensics**.

    2. **Filter Cameras**: Use the top filter bar to filter by status (`Active Recording` / `Archived`), location (`Pune` / `Mumbai`), or type (`Fixed` / `PTZ` / `ANPR`).

    3. **Open Camera Inspection**: Click `🔍 OPEN CAMERA` on any camera card (e.g. `CAM-04`) to view full resolution stream preview, metadata, and 24-hour timestamp markers.

    4. **Play Video Clips**: Use player controls (`▶`, `⏮ 10s`, `⏭ 10s`) to inspect suspect sightings and ANPR detections.



    5. Generating & Exporting Official Investigation Dossiers


    1. Navigate to **📄 Investigation Dossier**.

    2. Review the automatically generated person-scoped summary report.

    3. Click **`🖨️ Print / Export PDF Dossier`** at the top right of the dossier card.

    4. Set print destination to **Save as PDF**, paper size to **A4**, and save the official document.
