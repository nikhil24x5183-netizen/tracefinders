# TRACE FINDERS — AI-Powered Criminal Network Analysis & Evidence Fusion System

**SIH 2026 Problem Statement:** SIH26189 — AI-Powered Criminal Network Analysis System

## Overview
TRACE FINDERS is a comprehensive criminal network intelligence workstation engineered for law enforcement agencies, SCCIC units, and forensic analysts.

### Key Capabilities
- **Person-Scoped Investigation Dossier Engine**: Complete separation of all subject investigation contexts.
- **Link Analysis Knowledge Graph**: 360° unconstrained Vis.js canvas with 5 layout engines.
- **CCTV / DVR Forensics Workspace**: 12-camera inventory grid, 24-hour recording marker timelines, and event playback.
- **Multi-Hop Evidence Fusion & XAI Leads**: Explainable AI rationale, confidence scoring, and cross-domain correlation.
- **High-Fidelity A4 PDF Generation**: Native print/export dossier module.
- **Pure OLED Pitch Black Theme**: High-contrast, dark mode interface.
